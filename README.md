## 🤖 How I build with AI

- **Pair-programming with Claude:** I set the brief, the audience and the standard, and the AI writes most of the code. I review, test and redirect, the way I'd run a creative team.
- **GitHub for the workflow:** version control, a roadmap in Issues, and GitHub Actions running automated tests and weekly health checks.
- **Render for shipping:** every push to `main` goes live automatically.
- **Built to be found:** llms.txt, structured data and MCP so AI assistants and agents can discover the work, not just search engines.

I'm not a developer by trade. I'm a marketer who ships.
